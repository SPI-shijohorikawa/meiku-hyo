# 云端保存（Google 表格 + Apps Script）设置步骤

用店铺共用的 Google 账号操作，大约 5 分钟。只需要做一次。

## 1. 新建表格
1. 打开 https://sheets.new （用店铺的 Google 账号登录）。
2. 左上角把表格名字改成「メイク表データ（四条堀川）」。

## 2. 贴代码
1. 菜单「扩展程序（拡張機能）」→「Apps Script」。
2. 把编辑器里原来的内容全部删掉，把 `cloud/apps-script.gs` 的内容整个贴进去。
3. 暗号已经写好了（`const PASS = "9";`），不用改。
4. 点上面的保存图标（💾）。

## 3. 发布成网页应用
1. 右上角「部署（デプロイ）」→「新しいデプロイ」。
2. 左边齿轮「種類の選択」→ 选「ウェブアプリ」。
3. 设置：
   - 説明：メイク表
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 点「デプロイ」。第一次会要求授权：选店铺的账号 →「詳細」→「（安全ではないページ）に移動」→「許可」。
   （这是 Google 对自己写的脚本的固定提示，脚本只操作这一个表格。）
5. 最后会显示「ウェブアプリ」的网址（`https://script.google.com/macros/s/……/exec`），**复制下来发给我**。暗号不用发给我。

## 4. 设备上不用做任何设置
暗号已经固定成「9」，写在 index.html 和 apps-script.gs 里，设备上不用输入。打开メイク表页面，右上角显示「☁ 保存済み 12:34」就说明连上了。
第一次连上时，云端已有的数据优先；这台设备上有、云端没有的フル清掃和リネン记录会自动合并上去。

右上角的状态：
- ☁ 保存済み HH:MM：已经存到云端
- ☁ 保存待ち / 保存中…：正在保存
- ☁ 未保存（つながりません）：断网了，数据先留在这台设备上，联网后会自动保存
- ☁ 合言葉が違います（红色）：暗号不对，点一下重新输入

## 以后修改代码时
「部署」→「デプロイを管理」→ 铅笔图标 →「バージョン：新バージョン」→「デプロイ」。这样网址不会变。
